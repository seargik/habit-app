How to use

  1. Upload this public-safe app to GitHub Pages.
  2. Open it on iPhone in Safari and Add to Home Screen.
  3. Edit your private checklist inside the app on the phone.
  4. Export full JSON weekly as backup and for ChatGPT analysis.
  5. If app code is updated, keep the same URL and press Settings → Reload app update.
